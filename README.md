# HomeLink Wiki

Static documentation site for the **HomeLink** ecosystem: eight connected Minecraft mods
(NeoForge 1.21.1) built on a shared API, **HomeCore** — energy, an industrial furnace,
mining, farming, storage, a dashboard and tasks.

**Live site:** https://lkdm7.github.io/HomeLink-Wiki/

Bilingual (français at the root, English under `/en/`). Each mod page lists its requirements,
features, exact crafting recipes with inventory-accurate 3D block icons, in-game galleries and
download links. Includes instant search and cross-recipe navigation.

## Structure

- `docs/` — the published site (GitHub Pages serves this folder)
  - `docs/index.html` and the per-mod pages
  - `docs/en/` — English version
  - `docs/assets/` — stylesheet, script, item icons, screenshots
  - `docs/sitemap.xml`, `docs/robots.txt`
