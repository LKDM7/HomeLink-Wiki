HomeLink Dashboard 1.6.0

Centre de contrôle visuel générique de l'écosystème HomeLink : consulter les appareils HomeCore, exécuter leurs actions autorisées, recevoir leurs événements et organiser un tableau de bord personnel. Il interprète les schémas publics HomeCore et ne contient aucune intégration spécifique à un mod tiers.

Minecraft 1.21.1 NeoForge 21.1.250 Java 21 HomeCore 1.14.0+ (<2.0.0) : obligatoire HomeLink Energy 0.1.0+ : obligatoire

Blocs#

BlocRôle
HomeLink ServerCrée ou rejoint un HomeNetwork.
HomeLink DashboardÉcran affichant les appareils du réseau lié, jusqu'à 64 blocs du serveur.
Répéteur HomeLinkÉtend la portée radio de 64 blocs supplémentaires.

Premiers pas#

  1. Placer un HomeLink Server et clic droit.
  2. Créer un HomeNetwork (nom personnalisable) ou choisir un réseau existant.
  3. Placer un HomeLink Dashboard à moins de 64 blocs et l'associer au même réseau. Au-delà, poser des répéteurs.
  4. Utiliser les onglets HOME, DEVICES, ALERTS, NETWORK et SETTINGS ; le bouton ? ouvre le manuel intégré.

Interface partagée#

Dashboard partage le cadre, la palette et les contrôles de HomeLink Storage : contrôles de 18 pixels, info-bulles, bouton ? dans l'en-tête, présents dans les deux mods.

Fabrication#

Icônes : rendu 3D des blocs, comme dans l’inventaire ; les objets (lingots, composants…) gardent leur texture réelle.

Les composants HomeLink s'assemblent à l'Établi électronique HomeCore.

Performance#

Le scénario de vérification couvre 100 appareils et 800 métriques avec synchronisation réelle. Le suivi réseau courant est plafonné à 128 appareils ; le surplus est signalé dans l'interface.

Installer#

Installer homecore-1.14.0.jar, homelink_energy-0.5.0.jar et homelink_dashboard-1.6.0.jar dans mods, côté client et serveur.

Galerie#

Captures en jeu. Cliquer pour agrandir.
