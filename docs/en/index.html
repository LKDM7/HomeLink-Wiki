The HomeLink ecosystem

A suite of Minecraft mods (NeoForge 1.21.1) that turns a base into a connected home network: energy, an industrial furnace, mining, farming, storage, a dashboard and tasks. Every mod is built on one shared API, HomeCore.

Foundation

HomeCore

The shared API: devices, metrics, actions, events, home networks (HomeNetwork) and the HomeLink visual kit used by every other mod. Depends on none of them.

v1.14.0 · API 1.9.0

HomeLink Energy

Renewable energy production in HE: solar panels, wind turbines, a hydro branch and batteries, linked by copper cables.

v0.5.0

HomeLink Furnace

A parallel-smelting industrial furnace powered exclusively by HomeLink Energy. Three throughput and capacity tiers.

v0.1.0

HomeLink Quarry

Automated quarry: a visible mining head digs block by block, layer by layer, across a bounded area.

v1.4.0

HomeLink Farm

Crop monitoring, copper irrigation and harvesting by an autonomous robot, the FarmBot, with its charging station.

v1.5.0

HomeLink Storage

A connected storage network that indexes, searches, locates and centralizes real inventories through pipes.

v1.4.0

HomeLink Dashboard

A generic visual control center: view HomeCore devices, act on them and receive their alerts.

v1.6.0

HomeLink Tasks

Collaborative task boards, a mind map and real crafting progress to organize a HomeLink base.

v0.2.0

How to read this wiki#

Each mod has its own page with: its requirements (Minecraft version, NeoForge, dependencies), a summary of its features, its main blocks/items, their exact recipes, and a link to the matching GitHub repository.

HomeCore is required by every other mod: it is the shared API and the source of the four electronic components (circuit board, microprocessor, communication and control modules) found in almost every recipe. HomeLink Energy provides the energy contract: Furnace and Quarry depend on it to run.
