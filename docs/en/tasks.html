HomeLink Tasks 0.2.0

Collaborative task boards, a mind map and real crafting progress to organize a HomeLink base. Each project binds to a HomeNetwork and is shared between members; the task display makes the board viewable in-game.

Minecraft 1.21.1 NeoForge 21.1.252 Java 21 Requires HomeCore 1.14.0+ HomeLink Storage: optional integration JEI / REI: optional support

Role#

Tasks adds an organization layer to the ecosystem: projects containing boards (columns of to-do / in-progress / done cards), a mind map to link ideas, and priorities (Low, Normal, High, Urgent). Projects bind to a HomeNetwork through HomeCore: members share the same board and see the progress.

Projects and boards#

ViewUsage
ProjectsList, create and search projects; bind or detach a HomeNetwork.
BoardColumns of task cards with assignees, priority and a target quantity.
Mind mapVisually link the cards; recenter and pan freely.

Crafting progress#

A card can target a quantity of actually crafted items, not clicks, operations or prototypes. Progress shows as “X of Y crafted”. With HomeLink Storage installed (optional integration), tracking relies on the network's real inventories.

Recipe#

The task display is crafted at the vanilla table. It is the block that makes a project viewable in-game (three display sizes share the same base recipe).

Icons: 3D render of the blocks, as in the inventory; items (ingots, components…) keep their real texture.
